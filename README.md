A make.fun entry for **One Line, Zero Use: The Useless Superpower Sprint** — one original line naming a hilariously useless superpower.

`main.py` (pure Python standard library, deterministic) writes the line to `/output/entry.txt`:

> I can read minds, but only my own, and only the embarrassing thoughts, replayed on a loop, forever.

Run it with:

```sh
python3 main.py
```

The entry line is written to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
